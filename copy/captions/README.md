# Social captions

One file per episode (`epNN.md`), holding the Instagram caption as posted plus
any variants worth reusing. Captions used to be rewritten from scratch every
release because nothing was kept — this is the record.

## House format

```
SUPERVUOTO EPISODE NN BIT — <TITLE>
elmozzo VS <guest>

<2–3 short paragraphs: the feeling of the hour, not artist biographies.
No track or artist name-drops — the tracklist lives on the site.>

Listen on backintown.it or supervuoto.org
Cover image: @<photographer handle>

#supervuoto <genre tags> #radio #backintown #mixtape
```

## Rules

- **Mood, not bios.** Describe how the hour moves. The site carries the credits.
- **No track name-drops** in the caption; save them for the tracklist carousel
  or a comment.
- **Tag the guest** in the caption *and* in the image (separate reach pools),
  when they have a handle and want it.
- **Cover credit** is non-negotiable — always `@` the photographer.
- Hashtags: genre + `#supervuoto #radio #backintown #mixtape`. Genre tags
  should match the episode's `tags:` in `content/mixtapes.md`.

### Privacy

Some guests are minors. Default to **no surname, no handle, no school, no city,
no family relation** — the episode page carries whatever credit the guest agreed
to and nothing more. Per-episode exceptions are noted in that episode's file.
